# inkedpetal.dev

My personal website

This site started as part of Hack Club’s Pages, and over time I wanted to have a place where I could put basically everything I care about: software, robotics, hardware, art, random projects, and hobbies.

Live site: **https://inkedpetal.dev**

---

## what’s inside

### terminal-style landing page

The homepage is designed like a macOS terminal window.

It includes quick links to:

- About
- Projects
- Experience
- Poster Wall

The goal was to make the important stuff easy to find while still keeping the site playful.

---

## animated background grid

The site uses a grid of glowing bricks in the background to get some movement in.

---

## about me

It includes:

- what I’m studying
- what I’m currently interested in
- hobbies
- random facts
- a masonry-style photo grid

The photos intentionally have different aspect ratios instead of being forced into identical cards because I wanted the page to feel more like a pinterest collection than a dump.

## the poster wall

This is probably the weirdest part of the site.

The poster wall is a digital recreation of the physical posters hanging above my desk.

Each poster can be clicked to open a page about a different part of my life, including things like:

- robotics
- programming
- art
- crochet
- Hack Club
- TSA
- photography
- music
- this website itself

It was originally the main navigation system for the entire website.

I eventually moved the important information into the main terminal homepage so visitors would not have to hunt through every poster, but I liked the concept too much to remove it.

So now it lives as an optional side quest.

## AI usage / disclaimer

I did use AI as a development assistant while building parts of this website.

Most of the site coding, writing, visual direction, project content, and design decisions are mine, but AI helped me on some of the smaller implementation details.

In particular, I used AI assistance while refining things such as:

- hover animations
- transitions
- the animated rainbow divider
- the glowing background grid
- responsive CSS

I still reviewed, modified, tested, and integrated the code myself.

## poster artwork disclaimer

The poster images used in the interactive poster wall are based on physical posters I purchased from Temu and have hanging above my desk.

I recreated my real poster arrangement digitally because the wall itself is part of the concept of the website.

I do **not** claim ownership of the original artwork shown on those posters.

Unfortunately, the listings did not provide clear original artist attribution, so I do not currently know who the individual artists are.

If you are the original artist or know the correct attribution for any of the poster artwork, please contact me and I will gladly add credit or remove the image if requested.
